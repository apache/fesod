# Committed performance baseline

This directory holds the reference results for the performance regression gate
(see [`../benchmark.md`](../benchmark.md)):

- `jmh-baseline.json` — JMH results of the last accepted `FesodBenchmark` run. Generated by the
  *Benchmark* workflow; **must only ever be produced on an `ubuntu-24.04` GitHub runner with JDK 17
  (Temurin)**, because comparisons are absolute. Never commit a baseline generated on a local machine.
- `baseline-meta.json` — provenance of the baseline: source commit, JDK, runner, generation date.

On the first run after this branch merges, no baseline exists yet: the workflow detects the
bootstrap case, treats every benchmark as NEW (informational, gate passes) and opens a PR that
commits the initial baseline. After that, refresh it via
*Actions → Benchmark → Run workflow* with **update_baseline** checked; the workflow opens
a PR containing the new baseline plus a delta report against the previous one.
