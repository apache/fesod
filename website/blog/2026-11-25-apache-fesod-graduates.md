On November 24, 2026, the Apache Software Foundation (ASF) announced that Apache Fesod had graduated from the Apache Incubator and become a Top-Level Project (TLP). [Read the official ASF announcement](https://news.apache.org/foundation/entry/the-apache-software-foundation-announces-new-top-level-project-6).

<!-- truncate -->

Apache Fesod is a Java library for reading and writing spreadsheets, with a focus on performance and low memory use. Its streaming API processes data row by row, making it possible to work with large spreadsheets without loading the entire workbook into memory.

Fesod began as FastExcel and graduated from the Apache Incubator on November 18, 2026. During incubation, our community learned to make project decisions in the open and by consensus. As a Top-Level Project, Fesod is now governed by its own Project Management Committee (PMC). [Apache Incubator project status](https://incubator.apache.org/projects/fesod.html).

Thank you to everyone who has used and contributed to Fesod, from the FastExcel days through incubation. A special thank-you goes to our Incubator mentors for helping us put the Apache Way into practice.

We'll keep making Fesod a dependable library for spreadsheet processing in Java. If you'd like to help, you can report a bug, improve the documentation, or join a discussion. [Contributor guide](/community/contribution/).
