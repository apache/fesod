2026 年 11 月 24 日，Apache 软件基金会（ASF）宣布，Apache Fesod 已从 Apache 孵化器毕业，成为 Apache 顶级项目（TLP）。[阅读 ASF 官方公告](https://news.apache.org/foundation/entry/the-apache-software-foundation-announces-new-top-level-project-6)。

<!-- truncate -->

Apache Fesod 是一个注重性能和低内存占用的 Java 电子表格读写库。它通过流式 API 逐行处理数据，无需将整个工作簿加载到内存，也能处理大型电子表格。

Fesod 最初名为 FastExcel，于 2026 年 11 月 18 日从 Apache 孵化器毕业。在孵化期间，社区逐步建立了通过公开讨论、达成共识来作出项目决策的方式。成为顶级项目后，Fesod 由自己的项目管理委员会（PMC）负责治理。[Apache 孵化器项目状态](https://incubator.apache.org/projects/fesod.html)。

感谢从 FastExcel 到 Apache 孵化阶段一路支持 Fesod 的用户和贡献者，也特别感谢孵化器导师帮助我们在社区协作中践行 Apache 之道。

我们会继续维护 Fesod，让它成为一个可靠的 Java 电子表格处理库。欢迎报告问题、改进文档或参与社区讨论。[贡献指南](/zh-cn/community/contribution/)。
